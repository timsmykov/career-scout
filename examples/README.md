# Вымышленные примеры

Все тексты и ссылки вымышлены. Это не резюме владельца и не реальные вакансии.
Хеши — иллюстративные 64-символьные идентификаторы для проверки формата; алгоритм
канонизации и расчёт реальных content/evaluation keys реализуются в M1/M2.

worker-input.synthetic соответствует evaluation-pass.synthetic;
worker-input-borderline.synthetic соответствует evaluation-borderline.synthetic.
Для REJECT показан другой логический профиль Product, а не отрицание BA-опыта.
collection-report.synthetic показывает частичный сбор, не результат живого API.

Схемы проверяют форму, но не истинность утверждений и цитат по смыслу. Скрипт
проверки дополнительно сверяет дословные цитаты пары BA-примеров. Строгую проверку
всех runtime identity/versions и семантических оснований нужно реализовать отдельно.
