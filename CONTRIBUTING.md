# Разработка

1. Прочитать AGENTS.md и предметный документ.
2. Выбрать один этап docs/roadmap.md, записать критерий приёмки.
3. Не смешивать сборщик, UI, отправку откликов и правку резюме.
4. Подготовить тесты поведения и вымышленные фикстуры.
5. Проверить offline; сетевые запросы только отдельным явным сценарием.
6. Обновить документацию и статус готовности.

Формат изменений: короткое описание поведения и проверок. Не коммитить реальные
резюме, ключи или исходные вакансии. Изменения схемы требуют новой версии/миграции,
а не молчаливого прочтения старых данных по новым правилам.
