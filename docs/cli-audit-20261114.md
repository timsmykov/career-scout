## Найденное и исправленное

1. **Doctor отвергал допустимый single-CV setup.** Отсутствие Decisions и файла
   площадок давало ready=false при анализе существующего каталога с одним резюме.
   Добавлен `doctor --context`; проверяются нужные именно оценщику компоненты.
   Без context необходимость Decisions явно остаётся неизвестной.
2. **Неизвестная native-доставка могла повторяться.** Неопознанный exit/timeout
   Codex считался обычной технической ошибкой. Теперь он fatal/unknown. Перед
   возобновлением нового и прежнего анализатора проверяются незавершённые/unknown
   попытки, до увеличения бюджета. HTTP timeout/5xx и неопределённый Claude exit
   имеют ту же границу. Регрессии были воспроизведены до исправления.
3. **Потребители прежнего provider enum предполагали Codex.** Новые подключения
   проходят через общую фабрику в generic и legacy путях; отчёт billing читает
   frozen config и сохраняет совместимость старых минимальных запусков без model.
4. **Риск неверных token metrics при отсутствующем usage.** Отсутствующие или
   некорректные счётчики сохраняются как неизвестные, а не нулевой расход.
   Anthropic/Claude cache tokens и Gemini thought tokens учитываются отдельно.
5. **Дублирование схемы в schema mode увеличивало вход.** API JSON Schema
   передаётся один раз; JSON mode получает схему в промпте. Локальная проверка
   одинакова. Соответствующие регрессии сначала падали, после ремонта проходят.
6. **Ошибочные способы установки/авторизации исключены.** Навык входит в wheel;
   установщик отказывается перезаписать другую версию/пользовательские правки.
   Claude `--bare` не используется: локальная справка этой версии исключает OAuth.
   API login не подменяет подписку. Нельзя добавить буквальный api_key в config.

  roundtrip доказательств. 401/403/429/302/400/5xx, read timeout, запрет повторов,

- Ruff, runtime schemas/examples, локальные ссылки, public distribution guard,

## Границы вывода и дальнейшая работа

- Реальных source/model вызовов в этом аудите0. Работоспособность конкретного
  аккаунта/модели и актуальная тарификация всех провайдеров не подтверждены.
  Доступность JSON/schema зависит от модели; неподдерживаемая настройка даёт
  наблюдаемую ошибку без автоматического перехода на другой endpoint/режим.
- Независимая экспертиза и широкая семантическая точность остаются отдельной
  проверкой. Факт валидной цитаты не доказывает верность вывода.
- Multi-CV всё ещё требует внешний Decisions-коннектор; выбор API оценщика не
  устанавливает его. Single-CV с выключенным автоотсевом работает без него.
- Нет автоматического актуального прайс-листа, money budget и общего RPM limiter.
  Конечный бюджет вызовов/max output tokens/слоты действуют;429останавливает запуск.
- Ключи пользователей, production данные/контейнеры, subscriptions и settings не
  переносились и не изменялись. Установочные проверки использовали временные папки.
- Linux/Python3.12 остаются заявленной средой; Windows и другие версии не проверены.

Результат: расширенная alpha для пилотного использования с собственными доступами,
воспроизводимыми offline проверками и явно отделённой живой модельной приёмкой.
