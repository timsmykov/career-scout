# Подготовка разработки

Python 3.12, uv, Git. Из корня:

```sh
uv sync --locked --group dev
uv run --no-sync python scripts/check_repository.py
uv run --no-sync ruff check .
uv run --no-sync ruff format --check .
```

uv.lock фиксирует зависимости; pyproject задаёт разрешённые диапазоны.
Сетевой доступ на этом этапе нужен для установки пакетов, не для вакансий/LLM.
Виртуальная среда локальна .venv/, глобальные сервисы не меняются.

scripts/check_repository.py проверяет локальные Markdown-ссылки, схемы, вымышленные
примеры, полный набор профилей и выключенное состояние внешних вызовов.
Это проверка bootstrap-контрактов, не доказательство работающего сборщика.

После реализации тестов:
`uv run pytest -m "not live"`. Сейчас tests/ содержит только план.
Не добавлять фиктивный тест ради зелёного pytest.

## Будущий CLI (ещё не существует)

plan — показать source/query windows и бюджеты без сети.
collect — выполнить явный план, сохранить partial/full и cursor.
inspect — просмотреть сохранённую карточку, версию и признаки качества.
evaluate — отложенная команда будущего анализа; в текущий CLI не входит.
status — состояния, backlog и причины.
export — локальные результаты по retention policy.

Команды, аргументы и exit codes утвердить в M1/M2 и обновить этот документ.
Не публиковать README с несуществующими launch-командами.

## Окружение и пакет

src/career_scout/ пока содержит namespace и версию. Нет fake API clients или
притворного выполнения. Зависимости позволяют начинать M1 без глобального pip.

Обновление lock только явным `uv lock` и повторной проверкой.
Бизнес-тесты offline, respx для HTTP, временная SQLite для хранения, fake model
для графа. Live/model tests отдельно, без автоматической активации в CI.

Текущая приёмка требует только сборщиков/SQLite/экспорта. LangGraph не реализуется.
