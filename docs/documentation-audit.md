# Аудит документации 0.1

Процедура: gstack document-release; собственная проверка в текущей Codex-сессии.
Независимое ревью или внешняя сертификация не заявляются. Объём — основной
персональный путь и его граница с совместимыми прежними режимами.

| Контекст/версии/условия | agent-cli, context-evaluation | guides/candidate | quickstart | product, architecture |

## Исправленные противоречия

- README больше не представляет старые четыре профессии/TOML как настройки каждого пользователя.
- Схема архитектуры показывает реализованный context-1, а не future analysis/expiry.
- Статус источников больше не требует «реализовать адаптер HH» при существующем runtime.
- Практические команды отделены от датированных результатов и прежних интерфейсов.
- Карта модулей и тестов соответствует реальным файлам; несуществующие тестовые каталоги убраны из инструкции.
- Хэши и identity runtime описаны как реализованные, а не будущий этап M1/M2.
- Quickstart применяет приватную копию model connection, которую пользователь действительно редактирует.
- MIT/alpha и внешние предпосылки совпадают в README, первом запуске и аудите.

## Проверка документации

- check_repository валидирует JSON Schema/16вымышленных примеров и относительные ссылки.
- JSON новых руководств проверяется реальными ContextInput/SearchPlanInput/RunLimits.
- Примеры CLI сверяются с реальным parser; подготовительные команды можно выполнить без сети.
- Ruff и CI контролируют оставшийся runtime; документационные изменения не требуют нового сбора/LLM.
- Оформление публичного кейса и профиля проверяется чтением сохранённых файлов и браузером.

Аудит продукта0.1 остаётся датированным свидетельством исходной приёмки с484тестами,
а не автоматически обновляемым счётчиком каждого будущего коммита.

## Оставшийся долг

- Полный пошаговый опыт нескольких CV на чистой внешней установке остаётся
  ограничен непоставляемым Decisions helper. Его контракт описан; «one command install»
  не обещается. Это также продуктовый долг, который нельзя устранить только текстом.
- Подробные руководства преимущественно на русском; English README и публичный кейс
  дают международную точку входа, не полную английскую локализацию.
- Старые датированные протоколы, ADR и backlog сохранены как история и не пересчитаны
  задним числом. Текущие сведения начинаются с README и product-audit-0.1.
- Автоматическая проверка всех Markdown anchors и всех внешних URL не входит
  в check_repository; локальные файлы и выбранные публичные ссылки проверяются отдельно.

Версия остаётся0.1.0 alpha: оформление документации не является новым релизом.
