# ADR 0002: первый принявший профиль завершает

Статус: правило владельца принято; порядок профилей остаётся предварительным.
Дата: 2026-11-11.

Одна вакансия проходит профили последовательно. Первый валидный PASS завершает.
Прежняя схема независимого параллельного fan-out не применяется.
Непройденные профили skipped_after_accept, не REJECT. Отсутствие PASS не даёт
общего отказа при unknown/error. Параллельность только между вакансиями.

Последствие: выбран первый подходящий профиль, не доказанно лучший.
Изменение порядка меняет route_version и возможный выбор. Владелец подтверждает
порядок до live evaluate; схема ответа и роли отдельны от этого порядка.
