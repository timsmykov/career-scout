# ADR 0003: capabilities и политика отдельно для каждого источника

Статус: принято для проектирования.
Дата: 2026-11-11.

Четыре источника не объявляются четырьмя одинаковыми официальными search API:
HH официальный API; Trudvsem официальный REST; Habr проверенный frontend JSON
плюс HTML; SuperJob официальный API, пока не подключён.

Общий интерфейс скрывает форму ответа, но не ограничения доступа, пагинации,
полноты и хранения. Источник может быть blocked, остальные продолжают.
Не включать браузерный обход автоматически после API ошибки.
Право на код референса не даёт право хранить или передавать вакансии.
