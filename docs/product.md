# Задача и границы

**Версия0.1.0 alpha:** основной интерфейс — личный CLI с произвольными резюме,
пожеланиями, поиском и подборкой. [Итоговая приёмка](product-audit-0.1.md) фиксирует
реальные возможности и ограничения. Четыре профиля ниже — исходный сценарий
владельца и отдельный совместимый режим, а не обязательные профессии продукта.

12.11.2026 владелец разрешил анализ на LangGraph параллельно продолжающемуся сбору.
Коллектор сохраняет самостоятельность: его приёмка не зависит от модели или резюме.
Оценщики работают через существующую подписку Codex, не через отдельный model API.

## Результат

Владелец получает сохранённые полные вакансии с исходной ссылкой, состоянием
обработки. Пользовательская подборка включает только рекомендованные вакансии
и соответствующее резюме. Отказы/неизвестные остаются внутри анализа; отказ выбранных
оценщиков не означает отказ всех четырёх. Результат не теряется между запусками.

Выборка связана с технологиями/IT/финтехом/AI/ML; допускается технологическая
функция в обычной компании или помощь основателю технологической компании.

## Четыре профиля

product, business_analyst, business_assistant, automation.
business_assistant включает помощь предпринимателю и проектную координацию.
Профили равноправны по возможности принять вакансию; более ранний получает
приоритет фактического выбора. Подтверждён порядок: Product → автоматизация →
бизнес-ассистент → BA; первый PASS завершает маршрут.

Кандидат описан только актуальным текстом соответствующего резюме и явными
атрибутами владельца. Не импортировать неподтверждённый опыт из чатов и памяти.

## MVP

Read-only сбор через четыре адаптера; источники подключаются по доступности.
Полнота, версии, контролируемые повторы, фильтры, очередь, четыре логических
оценщика, сохранение результатов, локальный экспорт JSON/CSV.
Начальный интерфейс — CLI. OpenBot может позже инициировать запуск/читать отчёт.

## Вне MVP

Автоотклики, редактирование резюме, рассылки, поиск контактов, новый бот, UI,
расписание, LLM-координатор, обязательный Sol-ревьюер, vector DB, RAG по биографии.
Jobssearch, Geekjob, Jooble, LinkedIn, Wellfound не добавлены в выбранный набор.

## Входы и оставшаяся проверка

- В рабочем окружении 12.11 прочитаны четыре полных ролевых резюме с HH;
  рекламные блоки и элементы интерфейса исключены, источники сохранены приватно.
- Порядок подтверждён владельцем; публичные конфиги остаются выключенными примерами.
- География, формат, оформление — не придумывать значения; null означает не задано.
- 120 000 RUB net/месяц ранее было ответом для конкретного отклика.
  Это не установленный глобальный минимальный фильтр.
- Native Codex CLI подтвердил ChatGPT login и реальные вызовы gpt-6-luna/max.
- Качество вердиктов требует разметки и проверки на отдельной контрольной выборке;
  успешный вызов модели или совпадение цитаты сами по себе этого не доказывают.
- SuperJob: ключ проверен, владелец подтвердил разрешения на хранение; постоянный сбор включён.
- Хабр: контракт frontend не является опубликованным официальным search API.

Все модельные и сетевые вызовы имеют конечные бюджеты; автоматической отправки откликов нет.
