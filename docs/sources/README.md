# Источники вакансий

Все четыре адаптера реализованы: поиск, полная карточка, нативные страницы,
нормализация и сохранение. [Общий контракт](../multi-source.md),
[настройка поиска](../guides/collection.md), [аудит 0.1](../product-audit-0.1.md).

| Источник | Транспорт | Доступ | Существенная граница |
|---|---|---|---|
| [HH](hh.md) | Официальный API | Собственные credentials приложения | Глубина выдачи ограничена; большие окна делятся по времени |
| [Trudvsem](trudvsem.md) | Официальный REST | Текущий read-only путь без ключа | Свои поля, offset и составной source ID |
| [Habr](habr.md) | Frontend JSON + HTML | Текущий read-only путь без ключа | Публичный search-контракт не подтверждён; frontend может измениться |
| [SuperJob](superjob.md) | Официальный API | Ключ своего приложения | Постоянное хранение требует явного storage_allowed и разрешения владельца данных |

При приёмке 0.1 ограниченные живые поиск/detail прошли у каждой площадки.
Это проверка доступности в момент запуска, не гарантия будущей работы или полного
охвата. Полноту конкретного сбора определяет отчёт его run.

В агентском плане источники выбираются явно через sources, локальные параметры —
source_options. Географию HH нельзя подставлять в остальные адаптеры. Справочник
описывает реализацию; перед началом работы проверьте действующие условия своей
учётной записи. Пример не передаёт разрешения другого пользователя.
