# Безопасные отчёты

В репозитории и публичном Issue не должно быть реальных резюме, вакансий,
ключей, cookies, OAuth-кодов, подписочной авторизации и рабочих баз данных.
Подробный контракт данных — [docs/security.md](https://github.com/timsmykov/career-scout/blob/feat/evaluation-workers/docs/security.md).

Для обычного бага укажите версию, безопасную команду с заменёнными значениями,
error.code и воспроизведение на вымышленных данных. Не загружайте raw model
prompts, HTTP headers, `.env`, `auth.json`, SQLite или backup как приложение.

Если обнаружили уязвимость, не публикуйте способ эксплуатации с личными данными.
Доступность приватного GitHub-канала сообщения проверьте в разделе Security
репозитория; его включённость этим документом не обещается. Если такого канала нет,
сначала свяжитесь с владельцем через доступные контакты его GitHub-профиля,
без передачи секретов в публичном обсуждении.

0.1.0 — alpha. Наличие тестов не является пентестом или гарантией отсутствия
уязвимостей. Приложение использует внешние площадки и Codex на хосте;
аккаунты и их права пользователь настраивает самостоятельно.
